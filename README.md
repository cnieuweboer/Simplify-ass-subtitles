Scripts to simplify ass/ssa subtitles, embedded in mkv files.
Intended usecase is for playing videos on tv's or other weaker devices.

Copy all files to the folder where mkv files are stored.
Run "simplify_ass.bat" to replace embedded subtitles
Run "simplify_ass_no_replace.bat" to add the simplified subtitles, but not replace.
The changed mkv files are placed in an "output" subfolder.

The python script simplify_ass_lyrics_v2.py changes the ass/ssa files.
The Powershell script process_mkv_subtitles.ps1 automates simplifying subtitles for multiple video files.
